# Buynow — V1

Protótipo funcional inicial em Android nativo com Kotlin + Jetpack Compose.

Incluído:
- Home
- Busca
- Categorias
- Lista de produtos
- Detalhes do produto
- Carrinho
- Checkout com seleção de PIX/cartão/boleto/carteira
- Pedidos
- Perfil
- Navegação inferior
- Identidade visual azul e branca

Próximas integrações para transformar o protótipo em produção:
1. Backend/API e banco de dados
2. Cadastro/login real
3. Catálogo e estoque
4. Gateway Buynow e webhooks
5. Split e repasses
6. Antifraude
7. Entregadores e geolocalização
8. Painel vendedor e administrador
9. Push notifications
10. LGPD, segurança e observabilidade

Este projeto é uma base de interface e fluxo; os pagamentos ainda são simulados.
