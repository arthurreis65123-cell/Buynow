# Buynow V6 — Entregas e gestão de pedidos

- Acompanhamento de pedido pelo cliente com linha de status.
- Código de rastreamento e entregador preparados no pedido.
- Área do vendedor com pedidos das próprias lojas.
- Atualização do status do pedido: preparando, enviado e entregue.
- Endereço do cliente visível ao vendedor para preparação da entrega.
- SQLite migrado automaticamente com campos de rastreamento.
- API V6.

Backend:
```powershell
cd backend
npm install
npm start
```

O celular continua usando `http://192.168.0.8:3000`.

> Nesta versão ainda não existe distribuição automática de pedidos para entregadores nem pagamento real. Isso será a próxima etapa da logística.
