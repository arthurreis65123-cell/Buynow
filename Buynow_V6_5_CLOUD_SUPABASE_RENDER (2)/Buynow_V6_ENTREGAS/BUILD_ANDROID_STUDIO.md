# Buynow V4 — Android Studio

1. Extraia o ZIP.
2. Abra a pasta `Buynow_V4_MARKETPLACE` no Android Studio.
3. Faça o Gradle Sync.
4. Rode o app no emulador/celular.
5. Em paralelo, rode o backend com `npm install` e `npm start` dentro de `backend`.

Se o Android Studio pedir para atualizar Gradle/AGP, não atualize ainda: primeiro tente compilar com as versões já incluídas no projeto.
